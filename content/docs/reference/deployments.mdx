## Compatibility warning

The testnet instance was built from Burntato commit `07688de3193492aca399c8bbadc9321162e5f726`. It predates later current-source Recovery safety, configurable administration, purchase-activation, sponsorship provenance, and launch-curve work.

Do not expose a current-source selector merely because it appears in these docs. Compare the deployment's recorded source, installed loupe selectors, and live bytecode first.

## Local and hosted forks

Fork deployments are disposable environments, not stable network releases. Consume their generated public deployment artifact, validate the connected chain ID and bytecode, and do not copy an address from a prior fork restart.

Private RPC URLs and private keys never belong in a public deployment record.
